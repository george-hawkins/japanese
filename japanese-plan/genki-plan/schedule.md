# Schedule (Genki plan)

A lesson cycle is a run of A sessions followed by one B session. The layouts are in [sessions.md](sessions.md). Tick a box for each completed session: the last box in each row is the B session.

## Setup evening

1. Install the two Genki vocabulary decks in Anki, check them as described in [README.md](README.md), and suspend all cards except those of Lessons 1 and 2.
2. Create a Bunpro account, add the deck "Genki I 3rd Edition [Grammar]", choose the review type in which you type the answer, and leave Bunpro's vocabulary switched off.
3. Install the OTO Navi app and download the audio for the Genki I textbook and workbook.
4. Bookmark the Cure Dolly playlist and transcript, Tokini Andy's Genki I playlist on YouTube, the Tadoku free books page, and Natural Japanese set to Complete Beginner, "Unwatched Only" and sorted by "Easiest".
5. Order *A Dictionary of Basic Japanese Grammar*, the answer key if you do not want to use the PDF, and a notebook.
6. Download the 2012 N5 practice workbook files from <https://www.jlpt.jp/e/samples/sampleindex.html> and do not open them.
7. Set up the Japanese input method on your Mac.

Notes on Phase 1:

- Cycle 1 has two Cure Dolly lessons in every A session. This fits because Lessons 1 and 2 are material you know and because the review blocks are short in the first week, so the Genki block can run to an hour.
- From cycle 2, the two Cure Dolly lessons go in sessions A2 and A4.
- Cure Dolly's lessons run ahead of Genki in places. Lessons 13, 19 and 24 to 30 cover the passive, the causative and several structures from Genki II. Treat them as a first exposure.
- Lesson 11 has only six workbook pages. If you finish it early, start the next cycle.
- Order Genki II by cycle 9.

### Test 1 (T session after cycle 11) ☐
